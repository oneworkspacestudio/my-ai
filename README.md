# My AI

![My AI](web/public/logo.svg)

A place to ask questions, explore ideas and work on your code projects. Chat with models on your own PC through Ollama, or connect your OpenAI and DeepSeek API accounts.

Download the [Windows portable app](https://github.com/oneworkspacestudio/my-ai/releases). Open MyAI.exe to get started. With One Workspace, use your MyAccounts sign-in and keep conversations in your private My Drive area.

Choose a provider and model in each conversation. Models shows local models first, with expandable OpenAI and DeepSeek lists. Owner-queued downloads continue on the server after you leave the site, resume after My AI restarts, and share progress and installed models with every user on that server. Create a project by giving it a name. My AI creates its private folder in My Drive and a matching private repository in Git. Ask it to work on the project; completed changes are committed and pushed automatically. No folder paths or Git commands are needed.

Chat includes real clock/timezone, arithmetic, public web search/page reading, private conversation/attachment lookup, and your own project reads. Use Tools & skills to see available tools and explicit commands for models without automatic function calling. Project conversations can also create and edit text files inside the selected project using a model with tool support. The public read-only tools are available through a bundled MCP server.

This is an evaluation preview. Read the [setup guide](docs/SETUP.md), [feature support and acceptance](docs/SUPPORT.md) and [architecture decision](docs/ADR-001-architecture.md). For help, [open an issue](https://github.com/oneworkspacestudio/my-ai/issues).
